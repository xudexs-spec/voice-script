# 口播声纹 voice-script

把你的口喷（语音转文字 / 随口说的话），整理成一篇**能直接对着提词器念**的口播稿——而且越用越像你自己。

## 它干什么

- **输入**：你随口说的话
- **输出**：用**你自己的措辞和句式**写成的稿，不是 AI 腔
- **核心承诺**：保真 80–95%——你的语序、垫词、口头禅全保留

## 装进 WorkBuddy（三种方式任选）

1. **GitHub 链接导入**（最省事）：WorkBuddy 的「技能 / Skills」管理里选「从链接导入」，粘贴本仓库地址 `https://github.com/xudexs-spec/voice-script`
2. **压缩包导入**：本页 Code → Download ZIP，解压后导入
3. **本地路径导入**：`git clone https://github.com/xudexs-spec/voice-script`，指向克隆下来的文件夹

## 装完先做

打开 `onboarding.md`，跟 AI 走一次 **12–18 分钟的校准**（不做，出来的稿不像你）。
